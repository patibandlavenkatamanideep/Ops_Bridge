# Acceptance scenarios

Each of the 24 required scenarios in the build brief (§19, wording copied exactly), with the
automated tests that check its required result. Every test listed runs in `make verify` and
in hosted CI on pull requests (docs/STATUS.md has the latest runs).
`tests/contracts/test_acceptance_matrix.py` fails if this table drifts from the brief or
names a test that does not exist. All data is synthetic.

Levels: *unit* (no services), *integration* (real PostgreSQL roles, Keycloak, simulator over
HTTP, MCP), *browser* (Playwright against the running stack).
