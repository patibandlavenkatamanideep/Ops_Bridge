# Document fixtures

| File | Origin | Purpose |
|---|---|---|
| `malformed_truncated.pdf` | Hand-typed PDF syntax, deliberately truncated (no xref, no trailer, unterminated object) | Malformed-input rejection |
| `cupsfilter_text.pdf` | Generated by macOS CUPS `cupsfilter` from `cupsfilter_text.txt` — a different PDF producer than OpsBridge's fixture writer | Valid text-layer PDF from an independent generation path |
| `cupsfilter_text.txt` | Hand-written synthetic invoice text | Source for the CUPS PDF |
| `injection_supplier_email.txt` | Hand-written synthetic email containing instructions aimed at an AI system | Treated as data; must not change authority (Phase 3 tests) |

The scanned-document case is generated at test time as an image-only PDF with no text
layer (`simulator/minipdf.image_pdf`). It is a **synthetic** stand-in: no genuine paper
scan is included. A genuine scan remains an open fixture gap (see docs/STATUS.md).
