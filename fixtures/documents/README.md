# Document fixtures

| File | Origin | Purpose |
|---|---|---|
| `malformed_truncated.pdf` | Hand-typed PDF syntax, deliberately truncated (no xref, no trailer, unterminated object) | Malformed-input rejection |
| `cupsfilter_text.pdf` | Generated by macOS CUPS `cupsfilter` from `cupsfilter_text.txt` — a different PDF producer than OpsBridge's fixture writer | Valid text-layer PDF from an independent generation path |
| `cupsfilter_text.txt` | Hand-written synthetic invoice text | Source for the CUPS PDF |
| `rasterized_invoice.pdf` | `cupsfilter_text.pdf` rendered by macOS Quick Look (`qlmanage -t -s 2200`) to a 1700×2200 PNG (about 200 dpi), converted to a grayscale JPEG and wrapped in a PDF by `sips`: one image, no text layer | OCR path; its oracle is the hand-written `cupsfilter_text.txt` |
| `injection_supplier_email.txt` | Hand-written synthetic email containing instructions aimed at an AI system | Treated as data; must not change authority (Phase 3 tests) |

`rasterized_invoice.pdf` is an image-only PDF made by a different producer (Apple's
renderer) from a hand-written invoice, so OCR tests have an independent oracle. It is a
clean raster, **not a paper scan**: no skew, noise, stamps or handwriting. A genuine paper
scan remains an open fixture gap (docs/STATUS.md). The benchmark's scanned scenario is
generated at test time (`simulator/minipdf.image_pdf`).
